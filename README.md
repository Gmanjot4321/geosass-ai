GeoSass is a cutting-edge, AI OSINT investigator web application that pinpoints any photo's exact real-world location from city streets, cafes, and interiors to dirt, grass, and sky—complete with unhinged voice dubbing (via Gemini TTS & xAI Grok neural audio) and interactive satellite maps.

![GeoSass Banner](https://images.unsplash.com/photo-1526778548025-fa2f459cd5c1?w=1200&auto=format&fit=crop&q=80)

## ✨ Core Features

* **Multimodal Vision OSINT Engine:** Uses Google Gemini vision capabilities to analyze architecture, lighting angles, road infrastructure, flora, and soil substrates to deduce coordinates with extreme accuracy.
* **Neural Voice Dubbing:** Features expressive audio synthesizers and Grok voice personas (Sal, Ara, Rex, Eve, Leo) that dynamically roast the user's "stealth" attempts.
* **Interactive Satellite Radar:** Integrates Leaflet and Esri ArcGIS satellite imagery with live animated radar scanlines and precision zoom coordinates.
* **EXIF Metadata Scrubber:** Allows users to inspect and strip embedded GPS tags to test pure AI visual reasoning.
* **Live Interrogator & Debate:** Users can talk or chat directly with the AI host to challenge its coordinate deductions.
